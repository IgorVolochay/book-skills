# Скиллы из книг для Claude Code и Codex

Десять книг, превращённых в скиллы. С ними модель отвечает по правилам книги,
а не усреднённо.

> **Это форк** проекта [HinkoK/book-skills](https://github.com/HinkoK/book-skills).
> Пять исходных скиллов (Ильяхов, Восс, Фитцпатрик, Голдратт, Клир) взяты из
> оригинала. Я добавил ещё пять, по книгам о дизайне, типографике, брендинге и
> цвете, и разбил все скиллы по категориям.

## Что добавлено в этом форке

Пять новых скиллов созданы тем же инструментом
[book-to-skill](https://github.com/virgiliojr94/book-to-skill) (см. ниже) из
книг, лежавших в папке `books/`. Саму папку `books/` в репозиторий я не
добавлял: она в `.gitignore`.

Новые скиллы:

| Скилл | Глав в скилле | Замечания |
|---|---|---|
| `williams-design-basics` | 11 | покрыта вся книга; примеры шрифтов английские |
| `korolkova-living-typography` | 11 (из 22 глав книги) | главы 8–13 пересказаны сжато, детали по знакам и шрифтам проверяйте по книге |
| `airey-logo-identity` | 8 | главы 9–10 пересказаны кратко |
| `salenbacher-personal-brand` | 6 | статистика из издания 2013 года |
| `maksimova-color-intelligence` | 4 | цифры по влиянию цвета взяты из книги без проверки |

Во всех пяти скиллах иллюстрации книг не читались, примеры реконструированы
словами.

### Что не вошло

Книга Иоганнеса Иттена «Искусство цвета» (PDF в `books/`) оказалась сканом
без текстового слоя, а OCR в системе не установлен, поэтому скилл по ней не
создан. Чтобы добавить её, поставьте `tesseract-ocr` (с русским языком) и
`ocrmypdf`, распознайте PDF и повторите `/book-to-skill`.

## Установка

Claude Code:

```bash
git clone https://github.com/IgorVolochay/book-skills.git
cp -R book-skills/skills/* ~/.claude/skills/
```

Codex:

```bash
git clone https://github.com/IgorVolochay/book-skills.git
mkdir -p ~/.agents/skills
cp -R book-skills/skills/* ~/.agents/skills/
```

После копирования перезапусти Claude Code или Codex. Скилл подключается сам,
когда задача подходит под его описание. В Claude Code его можно вызвать и по
имени, например `/pishi-sokraschay`.

## Что внутри скилла

- `SKILL.md`: главные методики книги и указатель по темам
- `chapters/`: конспект каждой главы отдельным файлом, модель читает только нужную
- `glossary.md`: термины книги
- `patterns.md`: приёмы и техники
- `cheatsheet.md`: шпаргалка с правилами

Скиллы собраны инструментом [book-to-skill](https://github.com/virgiliojr94/book-to-skill).

Это конспекты для работы, а не текст книг. Сами книги стоит прочитать целиком.
