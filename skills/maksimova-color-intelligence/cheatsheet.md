# Шпаргалка: «Цветовой интеллект»

## Решающие правила
| Ситуация | Делай | Почему |
|---|---|---|
| Нужно успокоить | Холодные, разбелённые, приглушённые цвета | Снимают напряжение |
| Нужно взбодрить | Чистые яркие, тёплые | Заряжают энергией |
| Нужно «уменьшить» объект | Отступающие (холодные) | Кажутся дальше |
| Нужна весомость, люкс | Тёмные, зачернённые | Ощущение веса и статуса |
| Нужно «облегчить» | Светлые разбелённые | Воздушность (но теряется концентрация) |
| Офис в белом | Акценты и приглушённые полки | Белый давит |
| Нужен доверительный бренд | Тёмно-синий, зелёный в мягких вариантах | Надёжность |
| Нужно отстроиться | Выбери цвет конкурентов минус | Т-Банк против синих и зелёных |
| Международный бренд | Проверь символику по странам | Значения противоречивы |
| Дальше «красиво» | Задача, формат, исследование, тест | Алгоритм |

## Характер оттенков
| Цвет | Сильная сторона | Обратная сторона |
|---|---|---|
| Красный | сила, страсть, власть | агрессия, давление |
| Жёлтый | молодость, свобода | ненадёжность, назойливость |
| Синий | спокойствие, надёжность | отстранённость |
| Оранжевый | дружелюбие, энергия | чрезмерная бурность |
| Зелёный | баланс, природа | инертность, «токсичность» ядрёного |
| Фиолетовый | загадка, магия | на грани выносимости |
| Чёрный | защита, статус | дистанция |
| Белый | чистота | холод, отчуждение |

## Тревожные сигналы
- Цвет выбран «потому что красиво».
- Нет проверки на целевой аудитории.
- Копирование палитры без учёта культуры.
- Белые и бежевые стены без акцентов.
