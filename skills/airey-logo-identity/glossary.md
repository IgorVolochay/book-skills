# Словарь: «Логотип и фирменный стиль. Руководство дизайнера»

**Аванс**: часть оплаты до начала работы, обычно треть или половина (ch05)
**Бриф**: документ с целями, задачами, ограничениями, составленный по ответам заказчика (ch03)
**Воспринимаемая ценность**: ценность товара в глазах покупателя (ch01)
**Идентичность бренда (фирменный стиль)**: система знаков и правил, по которым узнают компанию (ch01)
**Карта ассоциаций**: схема связанных слов для поиска идей (ch06)
**Комитет**: те, кто принимает решения у заказчика (ch03, ch07)
**Контактное лицо**: сотрудник заказчика, с которым работает дизайнер (ch03, ch07)
**Монограмма**: знак из инициалов (ch02)
**Многосторонность (versatility)**: способность знака работать в разных носителях (ch01, ch02)
**Наброски (thumbnails)**: быстрые эскизы идей на бумаге (ch06)
**Ничего неуместного**: требование соответствия знака отрасли и аудитории (ch02)
**Редизайн**: обновление существующего фирменного стиля (ch04)
**Спекулятивная работа**: работа без гарантии оплаты, например конкурс логотипов (ch05)
**Твёрдая расценка**: фиксированная цена за проект (ch05)
**Pantone**: цветовая система образцов, показывается после выбора идеи (ch06)
**Pro bono**: работа бесплатно для некоммерческой организации (ch05)
**PDF для презентации**: зафиксированная версия работ, с датой в названии (ch06)
**Силуэт**: внешние очертания логотипа (ch02)
