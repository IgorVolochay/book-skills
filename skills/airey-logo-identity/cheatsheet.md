# Шпаргалка: «Логотип и фирменный стиль»

## Решающие правила
| Ситуация | Делай | Почему |
|---|---|---|
| Старт проекта | Бриф и исследование | Решения опираются на документ |
| Клиент хочет «красиво» | Спроси про его клиентов | Логотип для рынка, не для вкуса |
| Идея громоздкая | Оставь одну деталь | Запоминается одно |
| Знак сложный | Проверь в чёрно-белом и в миниатюре | Многосторонность |
| Хочется тренд | Откажись, выбери традицию | Долговечность |
| Редизайн известного бренда | Сначала опрос | Эмоциональная привязанность |
| Много эскизов | Покажи 3 лучших | Слабый портит выбор |
| Клиент спорит о цвете | Покажи цвет после выбора идеи | Цвет легко менять |
| Клиент настаивает на правке | Сделай и покажи свой рядом | Наглядность убеждает |
| Нет аванса | Не начинай | Риск неоплаты |
| Заказов много | Повысь цену | Спрос |
| Кризис | Не снижай, улучшай маркетинг | Качество и цена связаны |

## Числа и пороги
| Параметр | Значение |
|---|---|
| Аванс | треть или половина |
| Карта ассоциаций | минимум два дня |
| Размер миниатюры | около 1 дюйма |
| Концептов клиенту | несколько лучших (в примере три) |
| Запас по срокам | назови больше (2 недели как 3) |
| Падение продаж Tropicana | 20% за два месяца |

## Тревожные сигналы
- Нет брифа и не знаешь, кто решает.
- Идея требует две-три отличительных черты.
- Показываешь клиенту всё подряд.
- Презентация через посредника.
- Конкурс «на спекуляцию».
