# Шпаргалка: «Создайте личный бренд»

## Решающие правила
| Ситуация | Делай | Почему |
|---|---|---|
| Не знаешь, куда двигаться | Выполни задания 3–6 письменно | Знание себя основа бренда |
| Идея есть, спроса нет | Найди существующую нужду | Создавать спрос дорого |
| Страх пойти дальше | Проверь фидбэк у тех, кто искренне заинтересован | Ближний круг может мешать |
| Много слабостей | Усиль сильное | Слабость часто оборотная сторона силы |
| Нужна ясность направления | Образ будущего плюс миссия плюс 3 цели | Без цели действия беспорядочны |
| Нужно выделиться | Управляй различиями и мировоззрением | Бренд это различия в головах |
| Онлайн-образ расходится с офлайн | Выровняй их | Рекрутеры гуглят |
| Нужны фото | Профессиональный фотограф | 3 из 5 против 1 из 100 |
| Много сетей | Выбери те, что достоверно передают сообщение | Качество связей важнее количества |

## Числа и пороги
| Параметр | Значение |
|---|---|
| Цели | минимум 3 |
| Задачи | по 5 на каждый из 3 лет |
| Ревизия бренда | раз в полгода |
| Стадии жизни | отрезки по 7 лет |
| Тенденции | 3 значимых, горизонт 15 лет назад и вперёд |
| Фото | профессионал: 3 удачных из 5; любитель 1 из 100 |

## Четыре составляющие бренда
| Составляющая | Вопрос |
|---|---|
| Содержание | что ты знаешь и умеешь |
| Стиль | как ты это выражаешь |
| Убеждения | во что ты веришь, ценности |
| Чувство такта | как ты ведёшь себя с людьми |

## Тревожные сигналы
- Нет миссии и целей.
- Онлайн-образ не совпадает с реальным.
- Всё делаешь в одиночку.
- Работаешь на износ без плана.
