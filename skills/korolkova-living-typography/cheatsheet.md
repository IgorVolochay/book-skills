# Шпаргалка: «Живая типографика»

## Решающие правила
| Ситуация | Делай | Почему |
|---|---|---|
| Длинный текст | Нейтральная антиква или динамический гротеск | Не отвлекает, ритм |
| Знак, вывеска, мелкий кегль | Различимый шрифт, чёткие формы | Считывание по буквам |
| Нужно выделить фрагмент | Курсив или полужирный в гарнитуре | Минимально достаточно |
| Одни прописные | Разреди буквы | Апроши рассчитаны на строчные |
| Выделить строчные | Не разряжай | Нарушает ритм |
| Узкая колонка | Флаг вместо выключки по формату | Нет дыр и коридоров |
| Сочетание шрифтов | Сходство или явное различие, не «почти» | Конфликт |
| В конце строки предлог | Неразрывный пробел | Смысл и коридор |
| Висячая строка | Правка, переносы, трекинг | Ритм полосы |
| Тире в тексте | Тире, не дефис, без «дыр» | Профессиональный набор |

## Числа и пороги
| Параметр | Значение |
|---|---|
| Длина строки (текст) | 30–75 знаков, оптимально 55–60 |
| Ширина колонки (текст) | не короче 3 квадратов (≈55 мм), красиво до 7 квадратов (≈130 мм) |
| Базовый интерлиньяж | равен кеглю; в программах по умолчанию ≈120% |
| Интерлиньяж меньше кегля | не для текстового набора |
| Пункт | ≈ 1/72 дюйма (0,353 мм; Дидо 0,376 мм) |
| Межсловный пробел | 1/2 кегля (кириллица), 1/3 (латиница) |
| Допустимая подгонка знаков/апрошей | не больше ≈3% |
| Переносов подряд в книге | не больше 4 (в прочих изданиях 7–8) |
| Короткая концевая строка | не короче 1,5 абзацных отступов |
| Контраст штрихов | динамическая 1:2–1:3, классицизм до 1:10 |

## Выбор шрифта по типу
| Тип | Для текста | Для заголовка |
|---|---|---|
| Динамическая антиква | да (лучшая читаемость) | да |
| Переходная антиква | да (самая нейтральная) | да |
| Статическая антиква | нет, только колорит | да |
| Брусковый | по характеру | да |
| Динамический гротеск | да | да |
| Статический гротеск | при функционализме | да |
| Геометрический гротеск | нет | да |
| Акцидентный | нет | да, редко |

## Тревожные сигналы
- Много гарнитур «для разнообразия».
- Рамки и орнаменты без причины.
- Двойные пробелы, дефисы вместо тире.
- Светлые дорожки в тексте, висячие строки, висячие предлоги.
- Шрифт не соответствует характеру текста или эпохе.
