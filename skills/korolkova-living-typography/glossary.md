# Словарь: «Живая типографика»

**Абзацный отступ (красная строка)**: сдвиг первой строки абзаца вправо (ch10)
**Акцидентный (декоративный) шрифт**: шрифт для привлечения внимания (ch02, ch03)
**Антиква**: контрастный шрифт с засечками, делится на динамическую, переходную, статическую (ch03)
**Апрош (межбуквенный пробел)**: промежуток между буквами из двух полуапрошей (ch05, ch09)
**Базовый интерлиньяж**: равен кеглю (ch05)
**Брусковый шрифт**: шрифт с брусковыми засечками, «египетский», Clarendon (ch03)
**Выключка**: способ выравнивания строк: по формату, флагом, по центру (ch09)
**Висячая строка**: первая строка абзаца внизу колонки или последняя в начале (ch11)
**Висячий предлог**: однобуквенный предлог или союз в конце строки (ch11)
**Вгонка / выгонка**: подгонка текста под полосу (ch09)
**Глиф**: один знак в одном начертании (ch05)
**Гарнитура**: семейство начертаний (ch07)
**Гротеск**: рубленый шрифт, делится на старый, статический, динамический, геометрический (ch03)
**Динамика / статика шрифта**: происхождение от ширококонечного пера против геометрии (ch02)
**Дукт (ductus)**: одно движение руки при письме (ch02)
**Дыра**: белый промежуток, нарушающий ритм (ch11)
**Жидкая строка**: строка с непропорционально широкими межсловными пробелами (ch11)
**Зеркало набора, полоса набора**: область основного текста (ch08)
**Интерлиньяж**: расстояние между базовыми линиями строк (ch05, ch09)
**Капитель**: строчные знаки с рисунком прописных (ch06)
**Кегль**: размер шрифта, высота кегельной площадки (ch05)
**Кернинг**: поправка расстояния между конкретными парами знаков (ch04)
**Колонтитул, колонцифра**: навигационные элементы (ch10)
**Коридор (ручей, river)**: совпадение межсловных пробелов в строках подряд (ch11)
**Короткая концевая строка**: последняя строка абзаца короче 1,5 абзацных отступов (ch11)
**Курсив**: особый рукописный по духу рисунок шрифта (ch06)
**Лигатура**: слитые знаки с изменённым рисунком (ch04)
**Минускульные / маюскульные цифры**: строчные против прописных (ch06)
**Модуль, сетка**: система опорных линий страницы (ch08)
**Отбивка**: увеличение расстояния между элементами (ch10)
**Пункт**: основная единица типометрической системы (ch05)
**Разрядка**: равномерное увеличение апрошей в фрагменте (ch09)
**Рубрикация**: заголовки, подзаголовки, выделения (ch01, ch10)
**Различимость (legibility)**: считываемость знаков издали и в плохих условиях (ch01)
**Удобочитаемость (readability)**: качество шрифта и набора для длинного чтения (ch01)
**Флаг**: выключка в левый (правый) край с неровным краем (ch09)
**Цвет набора**: общий серый тон полосы (ch07, ch09)
