# Гл. 6. Классификации шрифтов

## Главная мысль
Единой классификации не существует. Автор берёт историческую классификацию (по динамике, контрасту, засечкам) и применяет её к выбору шрифта. Для текста лучшие нейтральные антиквы, для акциденции годятся все.

## Методики главы
- **Другие классификации (для справки)**: ГОСТ 3489.1-71 (устарел в момент принятия, 7 групп), классификация Вокса (humanes, garaldes, transitional, didones, slab serif, lineal), ParaType (Ефимов), торговые группировки магазинов шрифтов.
- **Классификация книги**:
  1. **Антиква (с засечками, контрастная)**:
     - **Динамическая**: умеренный контраст (1:2–1:3), наклонные оси, асимметричные засечки. Венецианская (самая «каллиграфическая», Jenson, Centaur), итало-французская (Garamond, Bembo), барочная (более контрастная, симметричные засечки). Динамическая нейтральная считается самым удобочитаемым текстовым шрифтом.
     - **Переходная**: больший контраст, вертикальные оси (Baskerville). «Пожалуй, самый нейтральный текстовый шрифт, подходит для почти любого сплошного набора».
     - **Статическая, классицистическая**: максимальный контраст (до 1:10), вертикальные оси, горизонтальные волосные засечки (Bodoni, Didot). Уступает по удобочитаемости, лучше для колорита эпохи. Вариант: газетная статическая (Cheltenham, Excelsior, «Журнальная», «Школьная»).
  2. **Брусковые**: «египетские» (Clarendon), либо по конструкции близкие к антикве, либо к гротеску (названия на Serif/Slab Serif). Применять для текста, соответствующего характеру, часто в паре с родственным гротеском.
  3. **Контрастные с односторонними засечками**: редки, как правило не для сплошного текста.
  4. **Гротески (рубленые)**:
     - **Старые** (XIX век, архаичные, американские «Gothic»).
     - **Статические** (швейцарские, середина XX века): максимальный порядок, равноширинность знаков, закрытые формы. Зрительно самый нейтральный, но не лучше для сплошного текста, уместны при функционализме.
     - **Динамические (в том числе гуманистические)**: открытые, негеометричные формы. Динамический гротеск наиболее пригоден для сплошного текста.
     - **Геометрические** (конструктивизм 20–30-х): для сплошного текста лучше не использовать.
  5. **Акцидентные (декоративные)**: сохраняющие традиционную форму; имитирующие письмо (формальные почерки, готика, стилизации под экзотику); имитирующие эпоху или способ нанесения (трафарет, пишущая машинка); прочие (геометрические, собранные из объектов, составные, свободные).

## Ключевые понятия
- **Антиква**, **гротеск**, **брусковый шрифт**, **акциденция**.
- **Очко (counter)**, **контраст**, **ось овалов**, **засечки (серифы)**.

## Антипаттерны
- Путать «шрифт с засечками» и «антиква»: не всякий шрифт с засечками антиква.
- Полагаться на одну классификацию как на истину.

## Выводы
1. Для сплошного текста: динамическая нейтральная или переходная антиква, динамический гротеск.
2. Статическая антиква, геометрический гротеск не для длинного текста.
3. Эпоху текста подчёркивай шрифтом соответствующего типа осознанно.
